# remote_job_guide

A one-page Next.js guide to remote platforms that hire developers from India, grouped into four ways in and ranked by how hard the entry test is (open sign-up, AI interview, practical, live coding, DSA, aptitude):

- Freelancer portals
- Direct remote job boards
- Test-and-match marketplaces (like Turing)
- Build-first portals (build the work first, get selected instead of interviewed)

All platform data lives in `lib/data.ts`.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
